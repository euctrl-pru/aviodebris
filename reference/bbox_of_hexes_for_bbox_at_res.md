# Return the bounding box of the H3 hexagons covering a user bounding box.

Return the bounding box of the H3 hexagons covering a user bounding box.

## Usage

``` r
bbox_of_hexes_for_bbox_at_res(bbox, resolution)
```

## Arguments

- bbox:

  the user bounding box

- resolution:

  the resolution of the H3 hexagons covering \`bbox\`

## Value

the bounding box containing the H3 hexagons covering \`bbox\`
