# H3 hexagons covering a bounding box.

H3 hexagons covering a bounding box.

## Usage

``` r
hexes_for_bbox_at_res(bbox, resolution)
```

## Arguments

- bbox:

  bounding box to be covered by H3 hexagons

- resolution:

  H3 hexagons' resolution

## Value

simple features of H3 hexagons polygons and relevant addresses
